## 5. S1 首个编码 Sprint（W2–W3）

### S1-01 `TH-03` 色盲安全（1.0 人周）



* 定义 `diffPalette: default | colorblind`；色盲模式使用蓝 / 橙 + 纹理 / 符号，不单靠红绿。

* 增加非颜色线索：`+`/`-`/`~` gutter 符号、变更类型图标、下划线 / 边框差异。

* 验收：色盲模拟下可区分增 / 删 / 改；对比度 ≥4.5:1；与语法高亮不冲突；设置持久化。

* 测试：`main.css` token 快照、`DiffView`/`DiffTree` 组件测试、axe 颜色对比检查。

* 依赖：S0 Token 映射；正式 token 化在 S2 随 `TH-01` 收敛。

### S1-02 `TH-09` 首屏无闪白（0.5 人周）



* 在 `index.html` 应用挂载前读取主题偏好，注入 `data-theme` 与背景色；支持 System 跟随 OS。

* 验收：冷启动无白闪；系统主题切换实时生效；重启记忆；失败回退 Light 不报错。

* 测试：启动截图对比（Light/Dark/System）；`store` 初始化单测。

### S1-03 `UI-06` Tab 溢出与会话布局（1.0 人周）



* Tab 超出可视宽度时进入 “更多” 菜单；当前 Tab 始终可见；关闭后焦点落到相邻 Tab。

* 会话恢复：Tab 顺序、激活项、滚动位置、布局宽度。

* 验收：1280/1440/1920 宽度下无横向滚动条；键盘可操作；恢复不串会话。

* 测试：`App.vue`/TabBar 组件测试 + 浏览器截图。

### S1-04 `CX-09` 比对预检（1.0 人周）



* 校验：空路径、路径不存在、同输入、包损坏、超大包、权限不足；给出可操作错误。

* 预检不通过不启动 job；用户可 “仍然继续” 仅限非阻断项（如同输入需显式确认）。

* 验收：错误文案中英文；不产生半成品 job；服务端同样校验，不依赖前端。

* 测试：Java `CompareInputValidationTest` 扩展 + 前端表单测试。

### S1-05 `UI-04` 审阅树头部壳层（0.5 人周，M2 完成）



* 只交付头部布局、筛选 chips、计数占位；不伪造进度。

* 未接 `CX-02` 时显示 “审阅数据待接入”，不显示 0/0 假数据。

* 验收：布局稳定；筛选 chips 可键盘操作；S3 接真实数据后不改布局。

* 测试：组件快照 + 可访问性检查。

### S1-06 `NF-02` 安全 v1（1.5 人周，安全 + Java）



* 归档路径规范化，拒绝 `..`/ 绝对路径 / 符号链接；解压总量 / 单文件 / 压缩比配额。

* 反编译超时可中断；失败降级文本 diff，不挂死。

* 报告 HTML 转义；Markdown/CSV 注入防护；日志脱敏。

* 验收：恶意夹具 v1 全过；正常包不误杀；错误可诊断。

* 测试：`UnpackTest`/`ArchiveDiffTest` 扩展；独立恶意夹具脚本。

### S1-07 回归与演示（0.5 人周）



* 全量 Java + 前端单测 / 构建；5 条主流程 UI 冒烟；录屏 3 分钟首跑。

## 6. Definition of Ready / Done

### 6.1 DoR（进入 Sprint 前）



* 需求 ID 与 PRD 章节可追溯；验收标准可测试。

* 设计稿 / 交互说明 / 空态 / 错误态齐全；中英文文案齐全。

* 依赖已满足或有明确 mock / 降级；测试夹具可用。

* 安全 / 隐私影响已标注；回滚开关已定义。

* owner、reviewer、预估工作量已确认。

### 6.2 DoD（完成）



* 验收标准逐条通过；无 P0/P1；已知问题有 owner / 日期。

* 单测 / 构建 / UI 回归 / 安全夹具全绿；性能不劣化。

* 代码只消费 token，无新增硬编码色值；i18n 无硬编码中文。

* 键盘 / 读屏核心流程通过；错误态 / 空态 / 加载态完整。

* 文档 / Release Notes / 迁移说明更新；PR 关联需求 ID。

* 特性开关可回退；回退演练通过。
