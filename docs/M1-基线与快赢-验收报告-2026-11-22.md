## 4. 验收结论与残余风险

- AC-21：代码层面已提供颜色 + 符号 + 纹理三重线索；`diff_palette.spec.js` 已编写但未在本机跑通，且未使用硬件色盲模拟器做人工像素核验，建议 UI 验收时补一次色盲模拟截图。
- AC-22：`scripts/check_theme_boot.mjs` 已直接执行内联脚本并通过暗/system 首帧断言；DoD 的“录屏检查无白闪”尚未录制，建议发布前在暗色偏好下做一次 0–300ms 录屏。
- AC-08：20 Tab 溢出菜单代码与 `tab_overflow.spec.js` 已编写；spec 未跑通，真实窗口宽度不足时的布局需浏览器人工确认。
- AC-09：同路径阻断已由 Java 单测覆盖；前端阻断态由 `preflight.spec` 覆盖。
- AC-23：Zip Slip 恶意夹具已通过既有 `ParseTest`/`ExportTest`；反编译超时已加双层护栏（子进程强杀 + 进程内 Future 限时）。进程内 CFR 线程无法被 Java 强制杀死，超时后为 daemon 遗留线程，属于 V1 已知边界。
- REQ-024：>200MB / >50k 条目按 warn 级返回并展示预计耗时，允许强制继续或取消。
- 快速包：`PreflightService` 增加包级短缓存（路径+mtime+大小+忽略扩展名），重复预检不再重读 zip 中央目录；首次打开仍受本机磁盘/杀毒扫描影响。
