## 1. 实现范围

### 1.1 六态主题模型

`src/store.js`：

- `THEME_ORDER = ['light','dark','midnight','paper','contrast','system']`，工具栏单按钮按此顺序循环。
- 首次启动默认 `system`，不再默认 `light`。
- `resolveTheme(pref)` 只解析 Bootstrap 底座：`light/paper → light`，`dark/midnight/contrast → dark`，`system` 读取 `prefers-color-scheme`。
- `resolveThemeToken(pref)` 返回实际 Token 主题名。
- `applyTheme(pref)` 校验六主题、持久化 `bempdiff-theme`、写入 `data-bs-theme`、`data-theme`、`data-token-theme`、`data-token-pref`、`color-scheme` 与首帧背景/前景；非法值回退 `light`。
- `lastThemeSwitchMs` 记录属性写入 + localStorage 的 JS 落盘耗时。
- System 监听 `matchMedia('(prefers-color-scheme: dark)')` 的 `change`，只重绘不写偏好。

### 1.2 首帧防闪白扩展到六主题

`webui/index.html` 的 `<head>` 内联脚本改成六主题表：

- `light/dark/midnight/paper/contrast` 各自 `mode/bg/fg`。
- 首次无偏好按 `system` 解析；已有偏好按六主题读取；非法偏好回退 `light`。
- 同时写 `data-bs-theme`（Bootstrap 底座）、`data-theme` / `data-token-theme`（Token 主题）、`data-token-pref`、`color-scheme`、背景/前景。
- 脚本位于 Bootstrap CSS 之前，冷启动不出现默认白底。

### 1.3 Bootstrap 变量与 Token 对齐

`src/styles/tokens.css` 增加 `html[data-token-theme]` 映射：

- `--bs-body-bg`、`--bs-body-color`、`--bs-secondary-color`、`--bs-secondary-bg`、`--bs-tertiary-bg`、`--bs-border-color`、`--bs-link-color`、`--bs-link-hover-color`、`--bs-primary` 及语义色。
- 视觉回归发现 Bootstrap 5.3 的 `bg-body-*` 实际走 `--bs-*-bg-rgb` 通道，仅映射 `--bs-*-bg` 不生效；午夜、护眼、高对比的工具栏/底栏仍显示 light/dark 默认底色。已直接覆盖：

```css
.bg-body { background-color: var(--bdf-canvas) !important; }
.bg-body-secondary { background-color: var(--bdf-surface-raised) !important; }
.bg-body-tertiary { background-color: var(--bdf-surface) !important; }
```

- `body` 铺 `--bdf-canvas` / `--bdf-text`，避免任何主题留下未着色白块。

### 1.4 ThemeStudio 与工具栏

- `ThemeStudio.vue` 六张卡片可点击切换，展示当前偏好、实际解析主题、上次切换 JS 耗时；卡片颜色全部来自 Registry。
- `ConfigDialog` 的「界面与高级」Tab 接入 ThemeStudio。
- `ToolBar.vue` 单按钮六态循环，图标和文案新增 Midnight/Paper/Contrast。
- `i18n.js` 增加六主题与 ThemeStudio 中英 key。

### 1.5 高对比焦点

- 全局 `:focus-visible` 使用 `--bdf-focus-ring`，2px outline，不改变布局。
- 补 `.btn:focus-visible` 覆盖：Bootstrap 自带 `outline: 0` 的优先级高于 `:where(...)`，若不覆盖，高对比下按钮无焦点环。
- 高对比 `focusRing` 与 canvas 对比度 16.7；真机 Tab 实测 `outline: rgb(0,255,255) 2px solid`。

### 1.6 校验脚本

新增/增强：

- `scripts/check_theme_matrix.mjs`：6 主题名、Bootstrap 底座、text/muted/focus/onAccent 对比度。
- `scripts/check_theme_boot.mjs`：六主题首帧、默认 System、非法回退、`data-token-pref`、内联脚本位于 Bootstrap CSS 前。
- `scripts/check_theme_switch.mjs`：jsdom + Vite SSR 加载真实 store，逐主题断言 DOM/持久化/非法回退，并记录 JS 落盘耗时。
- `scripts/check_theme_system.mjs`：模拟 `matchMedia` 变更，验证 System 实时跟随，且显式主题不被覆盖。
- `scripts/check_tokens.mjs` 增强：逐主题检查 CSS 块 20 个颜色 Token 是否齐全，并与 JS Registry 值逐项比对，防止手工同步漂移。

## 4. 实施中发现并修复的问题

1. **午夜/护眼/高对比工具栏仍用默认底色**：Bootstrap 5.3 的 `bg-body-*` 使用 `--bs-*-bg-rgb`，原 Token 只映射 `--bs-*-bg`。已按 Token 直接覆盖三个 utility。
2. **高对比按钮无焦点环**：Bootstrap `.btn:focus-visible` 的 `outline:0` 覆盖了通用 `:where(...)` 规则。已补 `.btn:focus-visible` 高优先级规则。
3. **焦点 Token 定义但未使用**：原 `--bdf-focus-ring` 只有 Registry/CSS 定义，组件没有消费。已加全局 `:focus-visible` 与按钮覆盖。
4. **浅色/护眼焦点对比不足**：light focus 从 `#86b7fe` 调到 `#0b5ed7`，paper 从 `#c99a5e` 调到 `#8a5a2b`，均 ≥3:1。
5. **CSS 与 Registry 双份颜色值可能漂移**：`check_tokens` 现在逐主题、逐 Token 与 JS Registry 比对；后续若改色必须两边同步，否则 CI 失败。
