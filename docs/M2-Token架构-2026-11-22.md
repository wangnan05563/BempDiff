## 2. Token 结构

- 颜色 20 个：canvas/surface/surfaceRaised/text/textMuted/border/accent/onAccent/focusRing，diff add/del/mod 背景与前景，risk breaking/high/medium/low/none
- 间距 6 个：xxs～xl
- 圆角 4 个：sm/md/lg/pill
- 字体 6 个：family/sizeXs/sizeSm/sizeMd/sizeLg/weightStrong
- 主题 6 个：light、dark、midnight、paper、contrast、system（system 按 `prefers-color-scheme` 解析，非法/缺失回退 light）

## 3. 校验规则

- 颜色仅接受 hex/rgb/rgba/hsl/hsla、`var(--x)`、transparent、currentColor 或 CSS 命名色；拼错值直接报错。
- `validateTheme(name)` 检查 20 个必需颜色 Token 是否存在且合法。
- `validateRegistry()` 检查 6 个主题名均注册，5 个静态主题全部通过。
- `initTokenRegistry()` 启动期校验；失败仅告警并回退 light，不阻断 UI。
- `check_tokens.mjs` 额外检查 Schema 中每个 `--bdf-*` 都在 `tokens.css` 出现，避免 JS/CSS 漂移。
