## 一、实现范围

### 新增纯逻辑模块
`bempdiff/webui/src/lib/review_tree.js`

- 默认筛选模型 `{ status:'all', highRisk:false, onlyFormatted:false }`，非法值归一为全部。
- `reviewTreeStats(tree, review, aiClassify)`：以差异树全量文件节点统计已审/未审/进行中/需复核/高风险/已分类/备注/书签/百分比，目录不计入。
- `passesReviewTreeFilter`：审阅四态 + 高风险 + 仅格式变化，与搜索/状态/风险/排除/忽略过滤取交集。
- `nextUnreviewedNode`：按传入候选顺序找当前文件后的下一个 `unreviewed`，末尾回绕；支持传入组合筛选谓词。
- `countFileNotes/countFileBookmarks`：兼容 `notes/noteCount/note` 与 `bookmarks/bookmarkCount/bookmark/bookmarked`，为 T06221 预留，不伪造数据。

### DiffTree.vue
- 新增 `dt-review-head`：`已审 X/Y · %`、`高风险 N/M`、`备注`、`书签`。
- 新增 chips：全部 / 未审 / 进行中 / 需复核 / 已审 / 高风险 / 仅格式变化；选中项显示计数，再次点击当前状态回到全部。
- 新增 `审阅队列` 视图：仅可审阅文件，按 AI 风险降序 + 需复核/未审/进行中/已审 + 路径排序；树/队列视图下排序菜单禁用。
- `clearAllFilters()` 现同时清搜索、4 个状态、风险与审阅 chips；空态与原清除入口共用。
- 筛选持久化：`bempdiff.treeReviewFilter`；自动跳转开关：`bempdiff.autoNextUnreviewed`（默认开，存 `0` 关闭）。
- 标记后自动跳下一未审：仅在审阅筛选为「未审」时，当前文件由非已审变已审后触发；尊重搜索/状态/风险/仅格式/高风险组合。目标位于折叠目录时按 `dir_tree` 的尾斜杠目录 key 自动展开全部父目录。
- `state.treeLocate` 仅负责滚动/高亮；自动跳转复用同一套定位逻辑。

### store.js
- `reviewAdvanceTick`：当前打开文件从未审/进行中/需复核 → 已审时自增一次；撤销已审不触发。
- `updateReviewFileState` 原有落盘、缓存、摘要逻辑不变。

### 文案与校验
- `lib/i18n.js` 增加中英文 review header/chips/queue/auto-next 文案；`dt.filtersCleared` 改为「全部过滤条件」。
- 新增 `scripts/check_review_tree.mjs` 与 `npm run check:review-tree`。

未改动 Java 服务端与审阅 API。

## 二、AC-07 验收

Given 选择「未审」+「高风险」，When 点击筛选，Then 列表仅显示同时满足两个条件的文件。

纯逻辑夹具（4 文件，Foo 未审 HIGH、Bar 已审 HIGH、Baz 进行中 MEDIUM、README 未审 LOW 且仅格式变化）：

- 未审 + 高风险 → 仅 `src/Foo.java`。
- 仅高风险 → Foo + Bar。
- 仅格式变化 → README.md。
- 无 AI 分类时高风险筛不出文件。
- 从 Foo 向后跳下一未审 → README.md；尾部回绕 → Foo.java；高风险组合下无下一未审 → null。

真机 UI（Vite dev server 动态注入 `state.aiClassify`，避免改动生产数据）：

- 统计头：`已审 0/3 0%`、`高风险 1/3`；高风险 chip 由 disabled 变为可点。
- 点击「未审」+「高风险」后：树文件仅 `src/Foo.java`，命中 `1/4`（含 src 目录）。
- 截图：`docs/ui-regression-assets/t06220-dev-ac07-highrisk.png`。
