## 1. 实现范围

### 1.1 Compare Bar

新增 `CompareBar.vue`，替代旧 `ToolBar` 成为新版工作区唯一顶部入口：

- 单行主栏：品牌、输入类型（包/目录）、老/新路径摘要、比对/停止、全局搜索、更多菜单；
- 路径摘要超长尾部截断，点击或按 ⌄ 展开编辑；编辑区含两侧完整 `PathBreadcrumb`、浏览、单侧上一层、两侧上一层、后退/前进、收起；
- 保留路径拖拽放入与自动类型推断；比对按钮与停止按钮共用现有运行态；
- 全局搜索直接驱动 `state.config.filterSearch`，搜索框内提供清除与聚焦树入口；
- 窄屏 (<1080) 额外显示「文件树抽屉」「智能分析抽屉」两个入口，桌面不渲染。

新增 `MoreMenu.vue`，收纳低频动作：

- 输出：报告预览、生成 Markdown 报告、差异资产导出（全量/JAR/CLASS）、下载管理；
- AI：整体风险分析、智能分类；
- 视图：主题循环、强调色、语言；
- 比对会话：最近比对与常用任务（模态框承载历史/命名会话）；
- 帮助、配置、回退旧版布局。

`StatusBar.vue` 增加常驻「旧版布局 / 新版布局」按钮，新旧布局均可一键切换。

### 1.2 三栏与断点

`main.css` 按 PRD §8.1 落地：

| 视口 | 左栏 | 右栏 | 行为 |
|---|---|---|---|
| ≥1440 | 300px | 380px | 三栏 |
| 1280–1439 | 280px | 320px | 三栏 |
| 1080–1279 | 260px | 收起（44px 窄条） | 默认收起右栏 |
| <1080 | 抽屉 | 抽屉 | 单栏，中间 diff 占满整宽 |

- 树栏只有用户拖拽过（`treeResized=true`）才使用内联宽度，否则完全交给 CSS 断点；
- 左右栏拖拽、收起、专注模式保留；`focus-mode` 下抽屉也强制隐藏；
- <1080：左右栏改为绝对定位覆盖层，默认不占布局宽度；Compare Bar 抽屉入口按需打开，选中文件后树抽屉自动收起；
- 抽屉宽度 `min(320px, 86vw)`，树工具栏自动换行、裁剪横向溢出，避免窄屏内容穿透到 diff。

### 1.3 Feature flag 回退

- flag：`reviewCockpit`，默认 `true`；
- 优先级：URL `?reviewCockpit=0` > localStorage `bempdiff.reviewCockpit=0` > 默认新版；
- `setReviewCockpit` 持久化 localStorage；状态栏按钮与 MoreMenu 均可切换；
- 仅切换布局壳，`job / paths / tabs / review / activeKey` 共用同一 `state`，不重建比对会话；
- 旧 `ToolBar.vue` 保留，并补充 `legacy-toolbar` 标记用于回归定位。

## 2. 验收结果

测试环境：Chrome headless 1280×800 / 1440×800 / 1200×800 / 900×800；服务 `127.0.0.1:4180`；真实 folder compare job `job-431001`（3 个变化文件、1 个目录、30 行 diff、2 Hunk）。

### 2.1 AC-04：1280×800 无横向滚动

| 区域 | clientWidth | scrollWidth | 结论 |
|---|---:|---:|---|
| document | 1280 | 1280 | 无横向滚动 |
| body | 1280 | 1280 | 无横向滚动 |
| `.compare-bar` | 1280 | 1280 | 无横向滚动 |
| `.cb-main` | 1280 | 1280 | 无横向滚动 |
| `.cb-paths` | 780 | 780 | 无横向滚动 |
| `.app-main` | 1280 | 1280 | 无横向滚动 |
| `.tree-scroll` | 279 | 279 | 无横向滚动 |
| `.diff-area` | 668 | 668 | 无横向滚动 |
| StatusBar | 1280 | 1280 | 无横向滚动 |

- Compare Bar 高度 42px；左栏 280px、右栏 320px、中栏 668px；
- 路径编辑展开后：2 个 PathBreadcrumb、2 列各 628.8px，document 仍 1280/1280，无横向滚动；
- MoreMenu 打开时 document 仍 1280/1280，菜单 256×544，右对齐不越界。

### 2.2 AC-05：feature flag 回退且不丢数据

同一页面点击状态栏「旧版布局」：

| 指标 | 新版 | 旧版 | 切回新版 |
|---|---:|---:|---:|
| `.prow` diff 行 | 30 | 30 | 30 |
| `.tree-node` 树节点 | 4 | 4 | 4 |
| 审阅摘要 | 审阅 0/1 · 0% · Hunk 0/2 | 同左 | 同左 |
| Compare Bar | 有 | 无 | 有 |
| 旧 ToolBar | 无 | 有 | 无 |
| 横向滚动 | 无 | 无 | 无 |

持久化回退：

- localStorage `bempdiff.reviewCockpit=0` 后重载：旧 ToolBar 出现、Compare Bar 消失、job 仍 30 行/4 节点、审阅摘要不变；
- 改回 `1` 重载：新版 Compare Bar 恢复，job 与树节点仍保留。

### 2.3 断点矩阵

| 视口 | 左栏 | 右栏 | diff 宽度 | 横向滚动 |

| 1440 | 300 | 380 | 748 | 无（1440/1440） |
| 1280 | 280 | 320 | 668 | 无（1280/1280） |
| 1200 | 260 | 44（默认收起） | 890 | 无（1200/1200） |
| 900 默认 | 隐藏 | 隐藏 | 900 | 无（900/900） |

900 树抽屉顶部 42px，与 Compare Bar 底边对齐；抽屉打开时 diff 仍保持 900px，不被挤压。

### 2.4 核心交互

- 全局搜索输入 `Bar`：树节点 4 → 2（仅 `src` / `Bar.java`），清空后恢复 4；
- 路径展开编辑：2 侧面包屑、2 侧浏览/上一层按钮，收起后回到单行；
- MoreMenu：4 个分组（输出 / AI 分析 / 视图 / 比对会话），12 个菜单项；历史/命名会话模态框代码路径已接入；
- 布局切换、搜索、路径编辑、抽屉开关均未触发 document 横向滚动。
