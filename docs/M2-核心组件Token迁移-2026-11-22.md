## 2. 新增派生 Token

`src/styles/tokens.css` 追加组件级语义层，字面值只允许出现在该文件：

- 浮层/阴影：`--bdf-overlay`、`--bdf-overlay-strong`、`--bdf-overlay-soft`、`--bdf-shadow-color`、`--bdf-shadow-pop`、`--bdf-shadow-menu`
- 文件类型 12 色：`--bdf-type-class/jar/config/js/html/css/jsp/office/static/archive/other/missing`
- 语法 13 色：`--bdf-syntax-keyword/string/comment/number/ident/function/type/tag/attr/heading/link/code/op`
- AI 过程态：`--bdf-ai-thinking*`
- 查找命中：`--bdf-find-hit`、`--bdf-find-current`
- diff 派生：`--bdf-diff-add-row/del-row/mod-row`、`--bdf-diff-*-sign`、`--bdf-diff-*-inline`、`--bdf-diff-*-inline-uni`
- 色盲调色板：`--bdf-cb-add/del/mod` 及 bg/sign，暗色主题在 Token 层提亮

diff 行底色/符号/行内片段均由主题 `diffAddFg/diffDelFg/diffModFg` 经 `color-mix` 重算，因此 light/dark/午夜/护眼/高对比切换时同一语义一致，不再依赖 `[data-bs-theme="dark"]` 手写覆盖。
