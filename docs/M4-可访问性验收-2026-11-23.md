# BempDiff 0.2 M4 可访问性验收记录（T06233）

日期：2026-11-23｜范围：核心交互组件 + 五套主题 Token｜结论：**G4 可访问性门禁通过（结构类 axe + Token 对比度）**

## 1. ARIA 与键盘可达性

| 对象 | 覆盖点 | 证据 |
|---|---|---|
| ToolBar / CompareBar | 按钮可访问名称、分组 role、禁用态语义 | `a11y_axe.spec.js` ToolBar 扫描 critical/serious = 0 |
| AiConsole | 任务状态、折叠区、操作按钮名称 | `a11y_axe.spec.js` 分析完成态扫描 = 0 |
| ShortcutHelp | 对话框 role、标题关联、列表结构 | `a11y_axe.spec.js` 扫描 = 0 |
| CompareOverlay | 弹层焦点容器、按钮名称 | `a11y_axe.spec.js` 扫描 = 0 |
| DiffView | 行号列 `ln-pick` 可点击语义、折叠按钮 `role=button`/`tabindex=0`/Enter 可触发、Hunk 操作按钮 aria-label | 组件源码 + `gutter_ops.spec.js` |
| 全局快捷键 | 输入框/文本域/contentEditable 不劫持；`?` 打开速查 | `shortcuts.js` + `shortcuts.spec.js` |

> jsdom 无布局引擎，axe 的 `color-contrast` 规则不可靠，故测试显式关闭该规则；对比度由第 2 节 Token 计算单独验收。

## 2. 对比度（WCAG 2.1 AA，正文/差异前景 ≥ 4.5:1）

| 主题 | 正文 | 弱化文本 | 新增前景/底 | 删除前景/底 | 修改前景/底 |
|---|---:|---:|---:|---:|---:|
| light | 15.43 | 4.69 | 7.00 | 9.16 | 6.58 |
| dark | 11.85 | 7.43 | 5.51 | 8.43 | 9.36 |
| midnight | 16.07 | 7.79 | 9.63 | 8.48 | 11.01 |
| paper | 12.96 | 5.15 | 7.52 | 7.31 | 6.59 |
| contrast（高对比） | 21.00 | 21.00 | 10.39 | 5.86 | 12.11 |

计算口径：WCAG 2.1 相对亮度公式，取 `styles/tokens.css` 中 `--bdf-text` / `--bdf-text-muted` / `--bdf-diff-*-fg` 与对应 `*-bg`、`--bdf-canvas` 配对。最低值 4.69（light 弱化文本），全部 ≥ 4.5:1。

## 3. 焦点与键盘

- `Esc`：关闭查找 → 清除行选择 → 退出专注模式，逐级回退。
- 折叠行支持 Tab 聚焦 + Enter 展开。
- 审阅 Hunk/行按钮均有 `aria-label`/`title`，键盘可触发。
- 弹层关闭后焦点回到触发按钮（CompareOverlay / ShortcutHelp 组件实现）。

## 4. 已知边界

- 未做读屏软件（NVDA/JAWS）全流程人工走查；axe 只覆盖结构类规则。
- 对比度为 Token 级静态计算，未覆盖第三方 Bootstrap 组件全部状态色。
- 以上缺口不阻断 G4，列入 M5 发布说明"已知问题"。
