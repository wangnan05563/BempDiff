## 2. 安全硬化（T06230，AC-24 / AC-25）

### 2.1 Zip Slip 与解压炸弹（既有 + 回归）

- `PackageParser` / `NestedUnpacker` 对每个条目做规范化路径校验，拒绝 `..` 越界与绝对路径落盘；解压前累计声明字节、条目数与嵌套深度，任一超阈值即终止并返回可读错误。
- 熔断阈值：单包解压字节上限、条目上限、嵌套深度上限均集中在 `NestedUnpacker`，由 `PoisonPackageTest` 覆盖“压缩炸弹/条目炸弹/路径穿越”夹具，断言不 OOM、不越界写盘。
- AC-24：恶意夹具在阈值内终止，进程存活，错误进入任务 `ERROR` 状态并在 UI 展示。

### 2.2 XXE（AC-25）

- `OfficeTextDiff.parseXml` 使用 `DocumentBuilderFactory` 并设置：
  - `http://apache.org/xml/features/disallow-doctype-decl=true`
  - `external-general-entities=false` / `external-parameter-entities=false`
  - `setExpandEntityReferences(false)`、`setXIncludeAware(false)`
- 新增 `SecurityHardeningTest`：恶意 `DOCTYPE + 外部实体` XML 必须抛 `XML 解析失败`；正常 Office XML 仍可解析。Java 全量重跑 2/2 通过。
- AC-25：不读取本地文件、不执行外部实体。

### 2.3 YAML 深度限制

- `config_semantic.js` 增加 `MAX_YAML_DEPTH=64`，所有解析栈帧统一走 `push()`，超深嵌套抛“YAML 嵌套层级超过 64 层，已拒绝解析”。
- UI 捕获后降级原始文本 Diff，不阻塞页面；`config_semantic.spec.js` 80 层夹具断言拒绝、正常 YAML 仍解析。

### 2.4 CSV 公式注入

- 新增 `csv_export.js`：
  - `safeCsvCell` 对以 `= + - @`、Tab、CR 开头的单元格统一加单引号前缀；
  - RFC 4180 双引号转义（含逗号、换行、双引号）；
  - `buildDiffCsv` 输出路径/状态/类型，过滤目录行；
  - `downloadCsv` 生成带 UTF-8 BOM 的 CSV。
- `MoreMenu.vue` “输出”分组新增“导出差异清单 CSV”，`store.js` 暴露 `downloadDiffCsv()`，中英文文案齐备。
- `csv_export.spec.js` 覆盖六类公式前缀、逗号/引号/换行、目录行过滤与恶意路径。

### 2.5 诊断包脱敏

- `DiagBundle` 对 API Key、Token、密码、Cookie 等键统一替换为 `***`；日志只保留请求方法/路径/状态码与耗时，不写请求头与响应体。
- `AiTest` 覆盖公网模型调用前的密钥脱敏断言；诊断包导出后二次扫描无明文密钥。

## 3. 可靠性（T06232，REQ-019）

| 能力 | 实现 | 验证 |

| 任务取消 | `POST /api/job/{id}/cancel` 置位 `cancelRequested`，后台在阶段边界检查并置 `CANCELLED`；`JobStore` 对 QUEUED/RUNNING 均可取消 | `JobCancelTest` / `ServerApiHttpTest` |

## 4. 性能（T06231，REQ-018）

### 4.1 已实施优化

- `DiffView.vue` 虚拟滚动 + 窗口化渲染；仅渲染视口附近行，DOM 行数 <500。
- jsdom 下跳过 `ResizeObserver`（真实浏览器保留），避免超大虚拟列表反复重建 `heights`。
- `foldedRows` 无上下文行直接复用 `rows`；`hunkReviewedById` 一次计算；单 Hunk `hunkAtRow` 快路径；`diffCount` 计数循环，避免初始渲染实例化 20 万对象。
- `DiffTree.vue` 对 50k 节点使用扁平可见列表 + 虚拟滚动；筛选/搜索在 worker 外做 O(n) 索引，不递归渲染。
- `NestedUnpacker` 按需解包 + 全局 memo；`Job.releaseMemory()` 释放双侧快照字节。

### 4.2 实测/代理指标

| 指标 | 口径 | 结果 |
|---|---|---|
| 10k 行 diff 首帧 | Vitest + jsdom 整组件挂载，护栏 12000ms | **4669ms，通过**（`release/diff-perf-10k.txt`） |
| 10 万行对齐 | `alignLines` 纯函数 | 1349ms，输出 20 万行 |
| 10 万行行模型 | `buildRows` 纯函数 | 1713ms |
| 组件更新 | 10 万行 `onUpdated` | 93–119ms |
| 可见 DOM 行 | 滚动窗口采样 | 约 41 行，<500 |
| 50k 树 | `tree_perf_50k.spec.js` | 全量并行 19,855ms（护栏 30,000ms）；PRD 3,000ms 线以隔离单跑存证，见 `release/tree-perf-50k-isolated.txt` |
| 200MB 包 | 既有 `LargePackageTest` / 解析熔断 | Java 全量通过；真实 200MB 夹具耗时未单列 |

**说明**：jsdom 无真实布局/合成器，10k 行 4669ms 不是浏览器 FPS；10k 行滚动 ≥50fps 与 200MB 包 ≤30s 的真机采样列入 M5 回归环境复核，不作为 M4 单独伪造结论。

## 8. 已知边界（写入发布说明）

1. 服务重启后完整内存 Job 不恢复；需重跑同一对路径，审阅记录保留但新 job 需回挂。后续可做 job 快照。
2. 10k 行 50fps、200MB 包 30s 以 Java/纯函数/组件代理指标验收，真机帧率与包耗时列入 M5 采样。
3. 读屏软件全流程人工走查未做；axe 覆盖结构类规则。
4. Office 文档解析仅支持 Office Open XML；旧二进制 `.doc/.xls` 走 POI 有限能力。
5. 对比度按 Token 静态计算，第三方 Bootstrap 组件状态色未全覆盖。
