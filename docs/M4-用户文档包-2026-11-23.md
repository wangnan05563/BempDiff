# BempDiff 0.2 用户文档包（M4）

> 版本：0.2.0-rc（M4 硬化阶段）｜日期：2026-11-23｜适用：Win x64 首发
> 本包覆盖 T06234「更新产品文档」：用户手册、快捷键指南、报告结构说明、迁移说明。

## 1. 用户手册

### 1.1 启动与入口

1. 启动 `BempDiff.exe`（或开发模式访问 `http://127.0.0.1:4180/`）。
2. 首屏为 **Launchpad**：最近任务、收藏、比对模板、示例包、使用引导集中在一个页面。
3. 顶部命令栏按任务阶段渐进披露：选择路径 → 预检 → 开始比对 → 审阅/报告。

### 1.2 选择比对对象

- **包比对**：老包与右侧新包分别选择 `.jar` / `.war` / `.zip` 等归档。
- **目录比对**：选择两个目录；目录模式会把 Java 源码直接纳入报告。
- 左侧始终代表旧版本、右侧代表新版本，不做自动方向重排。
- 路径可输入、可浏览、可从最近任务恢复；失效路径会给出提示并支持重新定位。

### 1.3 预检与开始

- 开始前可执行 **比对前预检**：检查路径、体量、条目数、嵌套层级与风险。
- 预检只读，不创建任务；存在阻断项时需修正后再比对。
- `Ctrl+Enter` 可开始比对；大包解析为异步任务，界面显示阶段与进度。

### 1.4 差异浏览

- 支持双栏（split）、换行（wrap）与 Git 风格 unified 三种视图。
- 虚拟滚动只渲染可视窗口；超过 6 万差异行自动降级「简洁视图」（关闭行内高亮、默认折叠未变区），可手动展开完整差异。
- 差异行导航：`Ctrl/Alt + ↑/↓` 或 `j / k`。
- 行内查找：`Ctrl+F`，`n / p` 跳下一条/上一条。
- 行选择与复制：点击行号选择，`Ctrl+A` 全选，`Ctrl+C` 复制；Shift+点击可范围选择。

### 1.5 文件级审阅

- 每个文件按连续变化行聚合为 **Hunk**；支持 Hunk 级与行级标记。
- 标记后自动跳到下一个未审文件（可在审阅树中开关）。
- 审阅真源为服务端 `reviews/{jobId}.json`，刷新/重启不丢；旧 `localStorage` 标记首次访问自动迁移。
- 审阅树头部显示已审/未审统计，支持「未审 + 高风险」「只看书签」等组合筛选。
- 备注与书签：支持行级备注、书签、证据 Markdown 复制；导出报告时可选择是否附备注正文。

### 1.6 报告与导出

- 报告为 Markdown/HTML，包含概要、统计、风险、文件清单、证据与备注附录。
- 「输出」菜单支持：复制报告、导出 HTML、导出差异资产 zip、导出差异清单 CSV。
- CSV 导出默认带 BOM，Excel 可直接打开；以 `= + - @` 等开头的单元格已做公式注入防护。
- 导出采用临时文件 + 原子替换，失败不会覆盖上一份完整导出。

### 1.7 配置语义 Diff

- 自动识别 `.properties` / YAML / XML / JSON，按语义键值对齐，而不是纯文本行。
- 密钥类键（token/password/secret/key 等）在 UI 中脱敏展示。
- YAML 仅解析安全子集，嵌套超过 64 层直接拒绝并降级原始文本 Diff，避免栈溢出。
- 可切换回原始文本模式。

### 1.8 总览与 Insight

- 总览看板展示 KPI、Top 风险、文件类型分布、审阅进度。
- Insight 五页签：总览、影响面、风险、证据、建议；支持跳转到对应文件/行。

## 2. 快捷键指南

| 快捷键 | 作用 | 作用域 |
|---|---|---|
| `Ctrl+Enter` | 开始比对 | 全局 |
| `Ctrl+K` | 定位到差异树过滤框 | 全局 |
| `?` | 打开快捷键速查面板 | 全局 |
| `Ctrl/Alt + ↑/↓` | 上一处 / 下一处差异 | 差异视图 |
| `j / k` | 下一处 / 上一处差异行 | 差异视图 |
| `n / p` | 查找结果下一条 / 上一条 | 差异视图（查找面板打开时） |
| `Ctrl+F` | 差异内容内查找 | 差异视图 |
| `Ctrl+A` | 全选差异行（无原生文本选区时） | 差异视图 |
| `Ctrl+C` | 复制选中行（无原生文本选区时） | 差异视图 |
| `Esc` | 关闭查找 / 清除行选择 / 退出专注模式 | 差异视图 |

> 输入框、文本域、可编辑元素内不劫持全局快捷键。

## 3. 报告结构说明

1. **封面/元信息**：任务 ID、比对模式、左右路径、版本、生成时间、工具版本。
2. **执行摘要**：总文件数、修改/新增/删除、风险计数、审阅完成度。
3. **差异统计**：按类型/目录/文件类型分布；Top N 变化文件。
4. **风险与影响面**：高风险条目、公开 API/配置变更、依赖变化。
5. **文件明细**：路径、状态、增删行数、Hunk 数、审阅状态。
6. **证据与备注附录**：可选；默认包含备注正文，可显式排除；用户文本按 HTML 转义输出，防 XSS。
7. **AI 洞察（可选）**：仅使用已脱敏的本地摘要；默认不上传遥测。

## 4. 迁移说明

### 4.1 旧审阅数据（localStorage → 服务端 JSON）

- 首次打开旧任务时，客户端读取 `bempdiff.review` 旧结构并迁移到服务端 `reviews/{jobId}.json`。
- 迁移成功：内存态与服务端同时更新，旧标记保留（行号 + Hunk 状态）。
- 迁移失败：**保留旧 localStorage 原文不删除**，弹出提示；启动继续，不阻断进入工作台。
- 回退：清除服务端审阅文件后，旧数据仍在，可重试迁移。

### 4.2 主题与偏好

- 主题键 `bempdiff-theme` 支持 light/dark/midnight/paper/contrast/system；非法旧值回退 light。
- 布局、折叠窗口、行内粒度、复制行号等偏好均为独立键，缺失时使用默认值。

### 4.3 任务恢复

- 客户端保存最近 tab 布局（jobId、tabs、activeKey、pin）；服务端任务仍为 DONE 时自动恢复。
- 审阅状态独立于任务内存态：即使任务被淘汰，`reviews/{jobId}.json` 仍在。
- 服务端崩溃后内存任务会丢失；当前恢复路径为 Launchpad 最近记录 + 重新发起比对 + 服务端审阅 JSON 回挂。完整任务快照恢复列为后续增强项（见 M4 验收报告"已知边界"）。

### 4.4 兼容性

- 首发平台：Windows x64；JDK 21 运行时随包分发。
- 旧版导出 zip、HTML 报告、CSV 均可继续打开；新版 CSV 增加 BOM 与防注入前缀。
