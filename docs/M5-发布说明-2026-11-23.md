版本：`0.2.0`｜构建日期：2026-11-24｜平台：Windows x64 首发｜安装包：`release/BempDiff-0.2.0-setup.exe`（325,503,010 B）

## 1. 变更摘要

### 1.1 入口与工作区

- 新增 Launchpad：最近 10 条、收藏命名会话、WAR/目录/配置三模板、三步引导、示例包一键比对、失效路径重新定位。
- Compare Bar + MoreMenu 渐进披露：输出/AI/视图/会话分组，1280px 无横向滚动，窄屏 900px 抽屉。
- 审阅驾驶舱三栏布局：左树 300/260/240，右 AI 380/44，中间 Diff；1200px 以下右栏收起。
- Feature Flag `reviewCockpit`：`?reviewCockpit=0` 或 localStorage 可回退旧 UI，新旧共用 store。

### 1.2 审阅闭环

- 文件级审阅状态：未审/审阅中/已审/需复核；服务端 `~/.bempdiff/reviews/{jobId}.json` 为真源，localStorage 仅缓存/旧数据迁移。
- Hunk 标记自动推进下一未审文件；支持手动覆盖、撤销、键盘 `j/k`、`n/p`。
- 备注/书签/证据摘录；报告默认含“证据与备注附录”，可排除备注正文，保留计数。
- 旧 localStorage 行级标记自动迁移；失败保留旧数据并弹窗提示。

### 1.3 能力显性化

- Insight 五页签：总览、兼容、影响、证据、AI。
- 总览 KPI、Top 5 风险、变更类型/文件类型分布、建议回归；点击风险跳文件。
- 配置语义 Diff：properties/YAML/XML/JSON 键路径对齐，忽略顺序/注释/命名空间前缀；密钥脱敏，解析失败降级原始文本。
- 结构化 API：`/api/job/{id}/insights`，schemaVersion 1.0，分页/截断标记，兼容/影响/审阅/AST 摘要。

### 1.4 安全与硬化

- Zip Slip、解压炸弹字节/条目/深度熔断；导出越界校验。
- Office XML 禁用 DOCTYPE/外部实体（XXE）；YAML 解析深度上限 64 层。
- CSV 导出公式注入防护（`= + - @`/Tab/CR 前缀单引号）+ RFC 4180 转义 + UTF-8 BOM。
- 诊断包/日志脱敏 API Key、Token、密码、Cookie。
- 导出原子写：同目录临时文件 + `ATOMIC_MOVE`，异常清理，避免半成品覆盖旧文件。
- 任务取消 API；JobStore 200 上限，结束任务淘汰 + 运行时目录回收 + 内存回扣。

### 1.5 性能与可访问性

- DiffTree/ DiffView 虚拟滚动 + 窗口化渲染，DOM 行数 <500。
- jsdom 跳过 ResizeObserver；foldedRows 快路径；Hunk 已审一次计算；单 Hunk 快路径；diffCount 计数循环。
- 五套主题 + system，全部 Token 化；正文/差异前景对比度 ≥4.5:1（最低 4.69）。
- axe 结构扫描 critical/serious = 0；键盘焦点、Esc 分级回退、弹层焦点回归。
- CSV 差异清单导出入口。

### 1.6 版本与构建

- 应用版本从 `0.1.2026111703` 统一为 `0.2.0`（根 package、dev-shell、About/HelpDoc）。
- Electron 31.7.7（本机 `electronDist`）+ jlink JRE 25 + Java 25 sidecar（源码按 `--release 21` 编译测试，安装包内置 JRE 25）；NSIS x64 安装包。
- 打包依赖走 `registry.npmmirror.com` 镜像（winCodeSign 2.6.0 / NSIS 3.0.4.1 / nsis-resources 3.4.1）；本轮未做 Authenticode 签名（`CSC_IDENTITY_AUTO_DISCOVERY=false`）。
- 一键发布脚本支持 `GH_DRY_RUN=1` 只构建不发布。

## 3. 迁移指南

1. **升级前备份**：关闭 BempDiff，复制 `%USERPROFILE%\.bempdiff\reviews` 到备份目录；如仍使用 0.1 客户端，保留浏览器 localStorage `bempdiff.reviewed` 以便自动迁移。
2. **安装**：运行 `BempDiff-0.2.0-setup.exe`，支持自选目录；覆盖安装保留 `~/.bempdiff` 数据。
3. **旧审阅迁移**：首次打开旧任务时，若服务端无 `reviews/{jobId}.json`，客户端读取旧 localStorage 并迁移；失败弹窗提示“旧数据已保留”，不丢历史标记。
4. **主题迁移**：旧主题偏好非法/未知时回退 `light`；`system` 跟随操作系统亮暗。
5. **回滚**：设置 `?reviewCockpit=0` 或 localStorage `reviewCockpit=0`，旧 UI 与新 UI 共用同一 store 和审阅 JSON；回滚不删数据。
6. **数据位置**：审阅 JSON `%USERPROFILE%\.bempdiff\reviews`；运行时解包 `%USERPROFILE%\.bempdiff\runtime`（任务淘汰/退出清理）；Electron 配置在 `%APPDATA%\BempDiff`。

## 4. 已知问题

1. 服务重启后内存 `Job` 的完整 DiffResult 不恢复；Launchpad 保留最近任务入口，审阅 JSON 保留，但需重跑同一对路径并重新挂载审阅。后续版本做 job 快照。
2. 10k 行滚动 ≥50fps、200MB 包 ≤30s 目前以纯函数/组件/jsdom 代理指标验收；真机帧率与包耗时列入 M5 采样，不作为 0.2.0 硬承诺。
3. 读屏软件（NVDA/JAWS）全流程人工走查未做；axe 仅覆盖结构类规则，对比度为 Token 级静态计算。
4. Office 旧二进制 `.doc/.xls` 仅有限 POI 能力；复杂宏/加密文档可能降级。
5. 五方签认需真实责任人签署，签认记录见 `docs/M5-五方签认记录-0.2.0.md`；未签认前不得对外发布 stable。
6. 本轮安装包未做 Authenticode 签名，Windows SmartScreen 可能提示“未知发布者”；对外发布前需用企业证书重签并重新发布 SHA-256。
