# BempDiff 0.2.0 数据迁移与兼容验收（T06242）

日期：2026-11-23｜版本：`0.2.0`｜平台：Windows x64
结论：**旧 localStorage 行级审阅数据可迁移到新 JSON 结构；非法/空数据不污染新文档；写入失败路径保留旧数据并提示；Win x64 安装包已产出。**

## 1. 迁移契约

| 项 | 实现 | 证据 |
|---|---|---|
| 旧结构读取 | `readLegacyJob(jobId)` 读取 `localStorage` 中旧行级标记 | `webui/src/store.js` §doLoadReviewForJob |
| 结构转换 | `migrateLegacyReviews()` 生成 `schemaVersion/jobId/user/files[fileKey].lines`，并标 `migratedFrom=localStorage` | `webui/src/lib/review.js` |
| 行号清洗 | 只接受 number/string 的合法行号；拒绝 `null`、boolean、空串、负数、小数、越界值 | `review_migration.spec.js` |
| 无可迁移数据 | 返回 `null`，调用方保留旧 localStorage 原文，不写空文档 | `review_migration.spec.js` |
| 服务端写入 | `PUT /api/review/{jobId}` 成功后清理旧键并提示迁移成功 | `webui/src/store.js` §431-443 |
| 写入失败 | `catch` 分支设置 `reviewMigration=failed`、`reviewError`，toast「旧数据已保留」；本地展示不回滚 | `webui/src/store.js` §444-449 |
| 覆盖安装 | `~/.bempdiff/reviews` 与用户数据不随安装目录清理 | NSIS 安装脚本 + 发布说明 §3 |

## 2. 测试结果

- `src/__tests__/review_migration.spec.js`：**1 个文件 / 3 用例全部通过**（`release/webui-review-migration.txt`）。
  - 合法行号去重并保留，`migratedFrom` 正确；
  - 非法行号过滤，`'7'` 保留、`null` 拒绝，修复了 `Number(null)=0` 误造第 0 行的真实缺陷；
  - 空对象/空文件/null 输入返回 `null`，调用方保留旧数据。
- 前端全量回归包含该文件（见 `docs/M5-全量回归-2026-11-23.md`）。
- Win x64 首发包：`release/BempDiff-0.2.0-setup.exe`（见 RC 构建报告）。

## 3. 边界

- 迁移只处理旧版「文件 key → 行号数组」；旧版备注/书签如存在于其他 localStorage 键，不在本迁移范围（0.1 版本无此结构）。
- 迁移是「首次打开该 job 且服务端无审阅文件」时触发；已存在服务端文件时以服务端为真源，不覆盖。
- 服务端不可达时进入 `reviewError` 并保留本地缓存；下一次可重试，不丢旧数据。
