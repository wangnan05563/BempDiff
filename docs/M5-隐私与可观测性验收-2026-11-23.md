# BempDiff 0.2.0 隐私与可观测性验收（T06243 / 矩阵 REQ-042）

日期：2026-11-23｜版本：`0.2.0`
结论：**默认不上传遥测；诊断包脱敏 API Key/Token/用户目录；本地保留关键事件日志用于排障。**

## 1. 默认不上传遥测

- 代码库静态检索 `telemetry` / `sentry` / `analytics`，仅命中诊断包相关代码，无第三方遥测 SDK、无后台定时上报。
- 外部网络请求只发生在用户显式触发的 AI 调用、更新检查、用户填写的代理/模型端点；默认启动流程不发起分析数据上传。
- AI 调用前的脱敏由 `AiTest` 覆盖：公网模型请求不得携带 API Key、Cookie 等敏感字面量；本地模型不走同一脱敏路径（本地数据不出机）。

## 2. 诊断包脱敏

`DiagBundle` 只收集环境信息 + 日志尾部，构建时双保险：

1. 内容白名单：仅 env、版本、线程/内存摘要、日志 tail；
2. 行级脱敏：`apiKey=`/`token=`/`password=`/`Cookie`/`Authorization` 值替换为 `<redacted>`，用户 home 路径替换为 `~`；
3. 包体上限 `<5MB`，日志尾部截断。

`DiagBundleTest` 3 个用例覆盖：

- 密钥/Token/用户目录全部脱敏，`apiKey=<redacted>` 保留键名；
- 超长日志只保留 tail，包体与内容不溢出；
- 日志目录缺失时仍能产出仅环境信息的包。

## 3. 本地可观测性

| 事件 | 存放 | 用途 |
|---|---|---|
| 桌面壳启动/退出/后端拉起 | `bempdiff/logs/shell.log` | 定位安装态启动失败 |
| Java 后端启动、HTTP 绑定、任务异常 | `bempdiff/logs/backend.log` | 定位端口/类路径/任务错误 |
| 请求方法/路径/状态/耗时 | 后端日志 | 不写请求头/响应体，避免密钥泄漏 |
| 审阅状态 | `~/.bempdiff/reviews/{jobId}.json` | 崩溃后恢复人工标记 |
