## 影响与触发

原实现只绑定 `127.0.0.1`，但浏览器里的恶意页面仍可向 `http://127.0.0.1:18765/api/*` 发请求；通配 CORS 让响应可读，review/preflight/status 等接口可被跨站枚举、读取、篡改或删除。固定 `X-BempDiff-Request: 1` 头只能挡跨站表单，不能挡脚本或本机进程。

触发场景：用户打开恶意网页 → 页面 `fetch`/表单调用本机 API → 读取差异树、反编译源码、审阅备注，或写入大量审阅文档占满磁盘。

## 修复内容

1. `BempServer` 每次启动生成 32 字节随机 token；优先级：构造参数 > `-Dbempdiff.apiToken` > `BEMPDIFF_API_TOKEN` > `SecureRandom` 自动生成。
2. 所有 `/api/*` 统一认证：`X-BempDiff-Token`、HttpOnly + SameSite=Strict 会话 Cookie、GET 直链 `?token=` 三者任一有效；缺失/错误返回 401。
3. 首页 `GET /` / `/index.html` 下发 `BEMPDIFF_SESSION` Cookie；浏览器 `<a download>`、`window.open` 自动携带，不把 token 暴露给 JS。
4. `Origin` / `Sec-Fetch-Site` 校验：拒绝非 loopback Origin、`cross-site`、同机非白名单端口；白名单仅本进程端口、`BEMPDIFF_DEV_PORT`（默认 5180）、5173。保留 `OPTIONS` 但不返回 CORS 许可。
5. Electron 主进程生成同一 token，sidecar 通过环境变量获取；preload 通过 `bempdiff:api-token` 同步给渲染进程。
6. 前端新增 `lib/api_auth.js`：统一 `authHeaders()`，下载/诊断包直链用 `withToken()`；`client.js`、`store.js`、`ConfigDialog.vue`、`Download.vue`、`PreflightDialog.vue` 已接入。
7. token 比较使用 `MessageDigest.isEqual`；固定 CSRF 头仍独立校验，变更请求缺头返回 403。

## 已知边界

- review 接口仍未强制 job 必须存在；持有 token 的本机进程仍可写合法随机 jobId，受 M-16 的 300 文件/64MB 上限约束。
- 本机恶意进程仍可读取进程环境或应用内存中的 token，token 主要封浏览器跨站/无 token 调用，不是防本机提权。
