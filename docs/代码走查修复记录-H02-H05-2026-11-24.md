## 2. 代码改动

- `bempdiff/java_core/src/com/bempdiff/server/BempServer.java`
  - 新增 `HDR_REQUEST_GUARD` / `REQUEST_GUARD_VALUE` / `MAX_REQUEST_BODY_BYTES`。
  - 新增 `routeApi(...)`：GET/OPTIONS 放行，POST/PUT/DELETE 缺头返回 403；拒绝前对小请求体做有限 drain。
  - `readBody(ex)` 统一走 `readBody(ex, 8MB)`；新增 `readLimited` 与 `RequestTooLargeException`。
  - `handleReview` 使用 8MB 有界读取并返回 413；jobId 改用 `ReviewStore.isValidJobId`。
  - `addCors` 改为 `noCors`，删除 `Access-Control-Allow-Origin: *`；SSE 响应的通配 ACAO 也删除。
- `bempdiff/java_core/src/com/bempdiff/server/ReviewStatusCalculator.java`
  - `normalizeLines` 用 `HashSet<Integer>` 去重，保持原顺序。
- `bempdiff/java_core/src/com/bempdiff/decompile/Decompiler.java`
  - `File.createTempFile` 移到 `DECOMPILE_GATE.acquireUninterruptibly()` 之前；失败不会漏许可。
  - `deleteOnExit` 兜底；`finally` 删除失败只忽略，`release` 放在内层 `finally`，不会被 IOException 跳过。
  - `INPROC_CFR_POOL` 改为固定线程池 + `ArrayBlockingQueue`，拒绝时抛 `IOException` 并降级 javap。
  - 仅对非“`// [降级]`”结果调用 `diskPutAsync`，避免超时 javap 污染磁盘缓存。
- `bempdiff/webui/src/api/client.js`
  - `req` 和 `analyzeStream` 的 POST 请求统一携带 `X-BempDiff-Request: 1`。
- `bempdiff/webui/src/store.js`
  - 导出启动的裸 `fetch` 补同一请求头。
- 测试：
  - `ServerTestHarness` 普通请求/raw 请求补请求头，新增 `requestNoGuard`。
  - `ServerApiHttpTest` 新增“无请求头 403”“超 8MB 413（裸 socket 只声明 Content-Length）”。
  - `ServerStaticAndConfigTest` 改为断言 OPTIONS 不再返回通配 ACAO。
