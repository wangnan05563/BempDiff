## 2. 代码改动

- `bempdiff/webui/src/store.js`
  - 新增 `reviewRevision` / `reviewSaveChain`；`applyReviewDoc`、`updateReviewFileState` 递增版本。
  - `flushReview` 普通保存串行执行；`flushReviewNow` 捕获发起时 revision，只有本地没有新编辑才回填响应并置 `saved`，否则保持 `pending`。
  - `runCompare` 开始时先 flush 上一作业未落盘审阅（失败则中止新比对）；取消分支恢复 `previousView` 并返回 `false`；`finally` 按 jobId 清理。
  - 新增 `resetJobViewState()`；`reportRunSeq` / `classifyRunSeq` 保护报告和智能分类的旧响应。
  - `reportCache` 键改为 `<base|ai:category>@<jobId>`；报告响应与智能分类响应校验发起时 jobId。
  - `doLoadReviewForJob` 新增 `cachedReviewIsNewer()`；本地缓存较新时先展示并排入保存链补写。
  - `loadInsights` 请求前清空旧 `state.insights`，避免旧洞察在新 job 首屏闪回。
  - `beforeunload` 仅在 dirty/error 时尝试 keepalive，并用 `TextEncoder` 计算 UTF-8 字节数，超过 60KiB 不发送。
- `bempdiff/webui/src/components/Launchpad.vue`
  - `openRecent` 在 DONE 分支先 flush 旧审阅（失败提示并拒绝切换），再 `resetJobViewState`，然后设置新 job、加载审阅/洞察。
- `bempdiff/webui/src/components/StatusBar.vue`
  - 新增 `reviewSaveState === 'error'` 红色提示与“重试”按钮，读取 `reviewError`。
- `bempdiff/webui/src/lib/i18n.js`
  - 新增 `sb.reviewSaveFailed` / `sb.reviewSaveRetry` / `sb.reviewSaveTip` / `lp.reviewSaveBlocked` 中英文文案。
- 测试：
  - 新增 `review_save.spec.js`：PUT#1 在途时新编辑不被旧响应覆盖，第二次保存补写新状态。
  - 新增 `compare_cancel.spec.js`：后端 CANCELLED 时恢复旧审阅/洞察/分类，`runCompare=false`。
  - `reportCache.spec.js` 缓存键同步为 `ai:*@j1` / `base@j1`。
